### **Parte 2: Función de Ayuda para Graficar**

Para no repetir código, crearemos una función que nos permita graficar cualquier distribución discreta de manera sencilla. Esta función recibirá los valores posibles (eje x), sus probabilidades (eje y) y, opcionalmente, qué barras resaltar.

**Código para ejecutar:**

```r
# @title **A. Función para Graficar Distribuciones Discretas**
plot_distribution <- function(values, pmf, title, highlight = NULL,
                              highlight_color = "red", label = NULL) {
  df <- data.frame(k = values, prob = pmf)

  p <- ggplot(df, aes(x = factor(k), y = prob)) +
    geom_bar(stat = "identity", fill = "skyblue", color = "black") +
    labs(title = title, x = "Valores (k)", y = "Probabilidad P(X=k)") +
    theme_minimal(base_size = 14) +
    theme(plot.title = element_text(hjust = 0.5, face = "bold"),
          axis.text.x = element_text(size = 9))

  if (!is.null(highlight)) {
    df_high <- df %>% filter(k %in% highlight)
    p <- p + geom_bar(data = df_high, aes(x = factor(k), y = prob),
                      stat = "identity", fill = highlight_color, color = "black")
  }

  if (!is.null(label)) {
    p <- p + annotate("text", x = length(values)/2, y = max(pmf) * 0.9,
                      label = label, size = 5, color = "darkgreen")
  }

  print(p)
}
```

#### **3.1. Distribución de Bernoulli**

**Definición:** Modela un experimento con dos únicos resultados posibles: "éxito" (1) o "fracaso" (0). La probabilidad de éxito se denota como *p*.

- **Función de Probabilidad:** $P(X=k) = p^k (1-p)^{1-k}$, para $k = 0, 1$.
- **Media (Esperanza):** $E(X) = p$
- **Varianza:** $Var(X) = p(1-p)$

**Ejemplo:** Lanzamiento de una moneda una vez. Sea X = 1 si sale cara, 0 si sale sello. Sea $p=0.5$ la probabilidad de obtener cara.

**Código para ejecutar:**

```r
# @title **B1. Ejemplo de Distribución de Bernoulli**
n_bernoulli <- 1   # Un solo ensayo
p_bernoulli <- 0.5 # Probabilidad de éxito (cara)

x_bernoulli <- 0:n_bernoulli
pmf_bernoulli <- dbinom(x_bernoulli, n_bernoulli, p_bernoulli)

plot_distribution(x_bernoulli, pmf_bernoulli,
                  sprintf("Distribución de Bernoulli (p=%.1f)", p_bernoulli))
cat(sprintf("Media (Esperanza): %.2f\n", n_bernoulli * p_bernoulli))
cat(sprintf("Varianza: %.2f\n", n_bernoulli * p_bernoulli * (1 - p_bernoulli)))
```

#### **3.2. Distribución Binomial**

**Definición:** Modela el número de éxitos en *n* ensayos independientes de Bernoulli. Cada ensayo tiene una probabilidad de éxito *p*.

- **Función de Probabilidad:** $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$
- **Media (Esperanza):** $E(X) = n \cdot p$
- **Varianza:** $Var(X) = n \cdot p \cdot (1-p)$

**Ejemplo:** Lanzar una moneda 10 veces. Sea X = número de caras. $n=10$, $p=0.5$.

**Código para ejecutar:**

```r
# @title **B2. Ejemplo de Distribución Binomial**
n_binom <- 10
p_binom <- 0.5

x_binom <- 0:n_binom
pmf_binom <- dbinom(x_binom, n_binom, p_binom)

plot_distribution(x_binom, pmf_binom,
                  sprintf("Distribución Binomial (n=%d, p=%.1f)", n_binom, p_binom))
cat(sprintf("Media (Esperanza): %.2f\n", n_binom * p_binom))
cat(sprintf("Varianza: %.2f\n", n_binom * p_binom * (1 - p_binom)))
```

#### **3.3. Distribución Binomial Negativa**

**Definición:** Modela el número de ensayos de Bernoulli necesarios para obtener un número fijo de éxitos (*r*).

- **Función de Probabilidad:** $P(X=k) = \binom{k-1}{r-1} p^r (1-p)^{k-r}$, para $k = r, r+1, \dots$
- **Media (Esperanza):** $E(X) = r / p$
- **Varianza:** $Var(X) = r(1-p) / p^2$

> **Nota de R:** `dnbinom(x, size=r, prob=p)` devuelve la probabilidad de obtener **x fracasos** antes del r-ésimo éxito (misma convención que `scipy.stats.nbinom`).

**Ejemplo 1 (del PDF):** ¿Cuál es la probabilidad de obtener 5 éxitos antes de 3 fracasos si la probabilidad de éxito es p = 0.7?

```r
# @title **Ejemplo 1. Probabilidad de 5 éxitos antes de 3 fracasos**
r <- 5     # Número de éxitos
p <- 0.7   # Probabilidad de éxito
k <- 3     # Número de fracasos antes de obtener 5 éxitos

prob_nbinom_1 <- dnbinom(k, size = r, prob = p)
cat(sprintf("Probabilidad de obtener 5 éxitos antes de 3 fracasos: P(X=5) = %.5f\n",
            prob_nbinom_1))

# Momentos
esperanza_nbinom  <- r * (1 - p) / p
varianza_nbinom   <- r * (1 - p) / (p^2)
desviacion_nbinom <- sqrt(varianza_nbinom)

cat("\nMomentos en el Modelo Binomial Negativo\n")
cat(sprintf("Esperanza: E(X) = %.2f\n", esperanza_nbinom))
cat(sprintf("Varianza: V(X) = %.2f\n", varianza_nbinom))
cat(sprintf("Desviación estándar: %.2f\n", desviacion_nbinom))
```

**Ejemplo 2 (del PDF):** La probabilidad de un niño expuesto al COVID-19 se contagie es de 0.6. ¿Cuál es la probabilidad de que el 10° niño expuesto sea el tercero en contraerla?

```r

```

#### **3.4. Distribución de Poisson**

**Definición:** Modela el número de eventos que ocurren en un intervalo de tiempo o espacio, dado un promedio de ocurrencia ($\lambda$).

- **Función de Probabilidad:** $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$, para $k = 0, 1, 2, \dots$
- **Media (Esperanza):** $E(X) = \lambda$
- **Varianza:** $Var(X) = \lambda$

**Ejemplo 1 (del PDF):** Una central telefónica recibe en promedio 2 llamadas por minuto. ¿Cuál es la probabilidad de que en un minuto se reciban exactamente 3 llamadas?

```r
# @title **Ejemplo 1. Probabilidad de recibir exactamente 3 llamadas**
lambda_poisson <- 2
k <- 3

prob_poisson_1 <- dpois(k, lambda_poisson)
cat(sprintf("Probabilidad de recibir exactamente 3 llamadas: P(X=3) = %.5f\n", prob_poisson_1))

plot_distribution(0:14, dpois(0:14, lambda_poisson),
                  "Distribución de Poisson - P(X=3)",
                  highlight = k,
                  label = sprintf("P(X=3) = %.5f", prob_poisson_1))
```

#### **3.5. Distribución Hipergeométrica**

**Definición:** Modela el número de éxitos en una muestra de tamaño *n*, extraída **sin reemplazo** de una población finita de tamaño *N*, que contiene *K* éxitos.

- **Función de Probabilidad:** $P(X=k) = \frac{\binom{K}{k} \binom{N-K}{n-k}}{\binom{N}{n}}$
- **Media (Esperanza):** $E(X) = n \cdot \frac{K}{N}$
- **Varianza:** $Var(X) = n \cdot \frac{K}{N} \cdot \left(1 - \frac{K}{N}\right) \cdot \frac{N-n}{N-1}$

> **Nota de R:** `dhyper(x, m=K, n=N-K, k=n)` — cuidado con los nombres de los argumentos (`m` = éxitos en la población, `n` = fracasos en la población, `k` = tamaño de la muestra).

**Ejemplo 1 (del PDF):** Una urna contiene 10 bolas rojas y 20 bolas azules. Se seleccionan 5 bolas sin reemplazo. ¿Cuál es la probabilidad de seleccionar exactamente 3 bolas rojas?

```r
# @title **Ejemplo 1. Probabilidad de seleccionar exactamente 3 bolas rojas**
N <- 30   # Población total
K <- 10   # Éxitos en la población (bolas rojas)
n <- 5    # Tamaño de la muestra
k <- 3    # Éxitos en la muestra

prob_hyper_1 <- dhyper(k, m = K, n = N - K, k = n)
cat(sprintf("Probabilidad de seleccionar exactamente 3 bolas rojas: P(X=3) = %.5f\n",
            prob_hyper_1))

# Momentos
esperanza_hyper  <- n * (K / N)
varianza_hyper   <- n * (K/N) * (1 - K/N) * ((N - n) / (N - 1))
desviacion_hyper <- sqrt(varianza_hyper)

cat("\nMomentos en el Modelo Hipergeométrico\n")
cat(sprintf("Esperanza: E(X) = %.2f\n", esperanza_hyper))
cat(sprintf("Varianza: V(X) = %.2f\n", varianza_hyper))
cat(sprintf("Desviación estándar: %.2f\n", desviacion_hyper))

plot_distribution(0:n, dhyper(0:n, m = K, n = N - K, k = n),
                  "Distribución Hipergeométrica - P(X=3)",
                  highlight = k,
                  label = sprintf("P(X=3) = %.5f", prob_hyper_1))
```
